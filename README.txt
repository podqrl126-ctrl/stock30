株式投資30日講座 PWA

公開方法（GitHub Pages）
1. GitHubで新規公開リポジトリ stock30 を作成。
2. このZIPを解凍し、stock30_pwaフォルダ内のファイル（index.html、app.js、style.css、manifest.webmanifest、sw.js、iconsフォルダ）をリポジトリのルートにアップロード。
3. Settings > Pages > Build and deployment > Deploy from a branch、Branch: main / (root) を選択してSave。
4. 数分後に https://ユーザー名.github.io/stock30/ にChromeでアクセス。
5. Pixel 10のChromeの︙ > ホーム画面に追加 > インストール（またはショートカット作成）を選択。

注意：GitHub Pagesの公開リポジトリにアップロードしたファイルは公開されます。個人情報やAPIキーは入れないでください。
学習進捗・模擬投資はブラウザ内のlocalStorageに保存されます。別端末には同期されず、サイトデータ消去で失われます。エクスポート機能でバックアップできます。
株価はユーザーが入力する架空・手動価格です。リアルタイム相場には接続しません。売買は模擬で、実際の証券取引は行いません。
